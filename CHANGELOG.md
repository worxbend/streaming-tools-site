# Changelog

## 2.1.0 — Signal studio

### Added
- SceneDeck Android in the eight-tool catalogue, with APK download, setup guidance, app screenshots and a public privacy policy.
- A dedicated Android showcase with an optimized local image preview.
- Browser coverage for mobile navigation, privacy-page themes, visible scene previews, reduced motion and local-only requests.

### Changed
- Rebuilt the visual identity around oversized typography, lavender and violet surfaces, signal-yellow controls and a cable/orbit motif.
- Redesigned navigation, the connection map, tool directory, installation panels, onboarding, FAQ and footer.
- Applied shared dark/light themes to the privacy page, with persistent preferences and a responsive reading layout.
- Refreshed the favicon and social preview while retaining local fonts and dependency-free runtime behavior.

### Fixed
- Scoped scene-control handlers to buttons so preview state cannot interfere with keyboard selection or ARIA attributes.

Existing tool anchors, installation commands, outbound links and privacy wording are preserved.
